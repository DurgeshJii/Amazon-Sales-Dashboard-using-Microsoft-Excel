# 📊Amazon-Sales-Dashboard-using-Microsoft-Excel
This project presents an interactive Amazon Sales Dashboard developed in Microsoft Excel to analyze over 10,000 sales transactions. The dashboard provides comprehensive insights into sales performance, product demand, regional distribution, and city-level trends through interactive visualizations and KPI indicators.

# Dataset Information

Records: 10,000+
Cities: 23
Attributes:
Date
Sales Representative
Product
Units Sold
Price
Total Sales
City
State
Region
Day

# Key Insights

Generated ₹10.22 Million in total sales.
Sold 33,874 products across 23 cities.
Nestle Smarties Pop-Up recorded the highest sales volume (5,267 units).
Maharashtra and several major metropolitan regions contributed significantly to overall sales.
City-wise trends highlight demand fluctuations and market performance across locations.
Product-wise analysis helps identify top-selling and low-performing products for better inventory planning.
